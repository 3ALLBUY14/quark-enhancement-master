# 功能对照与移植差异

对象：原版 `PikPak 增强大师 v5.3.0`（digbug82，AGPL-3.0，82,239 行 / 3.6 MB） → 本版 `夸克增强大师 v0.1.0`（~3,930 行 / ~150 KB）

## 一句话结论

**能移植，但不是逐行翻译，而是「交互范式 + 功能清单」的重写。**
原版约 27 个功能域中，本版完整覆盖 12 项、部分覆盖 3 项、未覆盖 12 项。未覆盖的部分几乎都卡在**夸克没有对等的公开接口**（云归档、离线任务、秒传、云解压），而不是实现能力问题。体量压缩到约 1/20，是因为砍掉了官方页面的 DOM 重绘与内嵌播放器，改为自绘工作台。

---

## 一、架构层的六项根本差异

| 维度 | 原版（PikPak） | 夸克版 | 影响 |
|---|---|---|---|
| **鉴权** | 从 `localStorage` 读 Bearer token，脚本自行注入 `Authorization` 头，并监听失效→等待新 token 重试 | **Cookie 会话**（`__pus`/`__puus`），页面同源请求自动携带，脚本**完全不碰凭据** | 夸克版更安全也更简单；代价是 token 失效时**无法自愈**，只能提示刷新重登 |
| **接口形态** | 单域 `api-drive.mypikpak.com` + `/drive/v1/files:*` **动作式批量语义**（batchDelete / batchMove 等） | `drive-pc.quark.cn/1/clouddrive/*` **REST 语义**，多文件操作靠 body 里的 `filelist` 数组 | 所有批量逻辑需重写：原版一次调用完成，夸克需自行分片（本版按 100/批） |
| **分页** | `page_token` 游标翻页 | `_page` / `_size` + `metadata._total` 总数 | 递归扫描的终止条件不同 |
| **异步任务** | 多数文件操作同步返回 | 分享创建、转存均为 `task_id` + 轮询（`status:2` 完成 / `3` 失败） | 新增 `api.waitTask()`，并需处理超时 |
| **UI 注入** | 深度依赖官方 DOM 类名（`.pikpak-loading-container`、`.el-overlay` 等），并主动抑制官方 loading 遮罩 | **Shadow DOM 自绘工作台，零依赖官方 DOM** | 夸克改版不会让界面失效；代价是操作入口在工作台内，而非官方工具栏旁 |
| **元数据** | 列表接口直接返回 `md5`、时长等 | 列表**不返回 md5** | 精确查重改为「先按体积粗筛 → 复用下载接口返回的 md5 精算」，零下载成本 |

其余差异：原版有 1404 条 i18n 键 + 远程语言包，夸克版为内联中文 52 键（结构已预留）；原版的 turbo 模式（改请求行为加速）在夸克侧改为并发池 + 最小间隔的**节流**（方向相反——原版求快，夸克侧优先降低风控概率）；原版的 400/401 自动刷新链路在夸克版降级为「提示 + 中止」。

## 二、逐功能对照

### 完整实现（12 项）

| 功能 | 原版做法 | 夸克版做法 |
|---|---|---|
| 工作台 / 多选 / 快捷键 | 中栏文件列表 + 工具栏 + 快捷键 | 自绘 Shadow DOM 面板，选择模型与快捷键逐项对齐（F2/F8/Delete/Alt+D/Alt+U/Alt+I/Ctrl+A/Ctrl+I/Esc/Ctrl+C·X·V），快捷键可改 |
| 属性面板 | 名称/大小/数量/创建/修改/来源/资源链接/位置 | 名称/类型/大小/创建/修改/路径/FID（夸克列表无「来源」「资源链接」字段，改为提供 FID 与直链复制） |
| 文件透视 / 筛选 | 选中或整目录扫描 + 排除关键词 | 同左，另加递归子树扫描、类型/扩展名/体积区间/日期区间过滤，命中项可直接删除或导出 CSV |
| 文件查重 | 按体积/指纹分组 + 保留策略 | 同左，**新增精确 MD5 模式**（复用 download 接口的 md5） |
| 文件夹查重 | 相似度分析 | 双维度：子项内容签名完全相同（强判重）+ 名称相似度（二元组 Jaccard，阈值可调） |
| 批量重命名 | 正则/序号/大小写/全半角/前后缀 + 新旧名预览 + 保留策略 | 规则引擎逐项对齐，另加**模板模式**（`${name}/${ext}/${n}/${date}/${rand}`）、名称截取、冲突检测与重名自动规避 |
| 资源清理 | 保留策略（最新/最旧/最大/最小/名称长短） | 五类规则（空文件夹/0 字节/超大/长期未修改/指定扩展名）+ 同类保留策略 |
| 目录树导出 | Markdown / 文本树 | Markdown 表格 / 文本树 / JSON 三格式，含体积与类型统计 |
| M3U 导出 | 选中视频导出播放列表 | 同左，可选写入直链（直链有时效，默认关闭） |
| TXT 磁链提取 | TXT 预览 + 解析磁链 + 提交云下载 | 预览 + 提取（magnet/ed2k/thunder/直链）+ 去重汇总；**「提交云下载」未移植**（见下） |
| 下载器集成 | Aria2 / Gopeed / ABDM / IDM | Aria2 JSON-RPC（含连接测试）/ IDM 清单（TXT、BAT）/ 浏览器直下。**ABDM、Gopeed 未接入** |
| 以图搜图 | Google Lens / Yandex / SauceNAO / trace.moe | 同左，四引擎原样保留（该能力与网盘无关，实现方式完全一致） |

### 部分实现（3 项）

| 功能 | 缺什么 | 原因 |
|---|---|---|
| 分享管理 | 缺「分享代码/密码修改」「次数限制展示」 | 夸克对应接口未公开；已实现建链/取码/我的分享/取消分享/浏览与转存计数 |
| 数据迁移 | 原版是「打包选中项 + 迁移凭证」；本版用**批量创建分享**替代 | 夸克无迁移包接口，分享链接是最接近的载体 |
| 播放器 | 原版有内嵌增强播放器（HLS.js、字幕、旋转镜像、截帧、倍速、播放进度记忆、循环模式）；本版只有外播直达 | 内嵌播放需劫持官方播放器 DOM 与媒体流，与「零 DOM 依赖」的设计取舍冲突，留给 v2 |

### 未实现（12 项）

| 功能 | 为什么没做 | 可行路径 |
|---|---|---|
| 云下载 / 离线任务管理 | 夸克网页端离线接口未公开且风控严；原版的「防屏蔽磁链自动修复」是 PikPak 特有逻辑 | 需实机抓包确认接口，或走官方开放平台 API |
| 上传增强 / 秒传 | 夸克分片上传流程（`up_pre` → `up_hash` → `auth` → OSS 分片 → `finish`）已公开可查，但工作量约等于现有全部功能，且与「管理」主目标弱相关 | v2 独立实现；原版的 CID/GCID 计算是迅雷特有，夸克用 md5+sha1 |
| 链接收藏夹 / 云归档 | PikPak 用 `user/v1/settings?items=bookmark` 做持久化，**夸克没有对等的持久化接口** | 改用「脚本本地存储 + 网盘内隐藏目录」模拟，或在开放平台 API 上另建 |
| 批量解压 / 解压密码库 | 夸克有云解压能力但接口未公开 | 需抓包 |
| 下载加速 / 下载过滤 | 原版靠改请求与阿里 CDN 语义；夸克侧无对应抓手 | 不可移植 |
| 隐私模式（遮罩文件名） | 需注入官方列表 DOM 并遮罩，与零 DOM 依赖冲突 | 需要 DOM 桥接层，收益低 |
| 多语言（tc/en/ko/ja/id/ms） | 当前中文单语 | 结构已就绪（`T` 字典 + `t()`），补字典即可 |
| 设置云同步 | 依赖上传管线 | 随上传一起做 |
| 目录独立视图偏好 | 排序偏好已按目录记忆，视图偏好未做 | 低成本，可补 |
| 官方 loading 遮罩抑制 | **夸克侧不适用**（原版是为了干掉 PikPak 的加载动画） | 不移植 |
| 分享解析历史 / 置顶 / 备注 | 需要本地持久化 + 检索 UI | 低成本，可补 |
| 登录态自动续期 | 夸克 cookie 由浏览器管理，脚本无法介入 | 不可移植 |

## 三、移植中新增的设计

原版没有、本版为了夸克场景补的：

1. **端点表外置**（`EP`）：所有路径与请求字段集中在脚本头部一张表里，官方改版只改这张表，业务代码不动。这是针对「夸克内部接口常年变动」的工程对冲。
2. **请求守卫**（`guard`）：并发池 + 最小间隔 + 指数退避重试 + 错误归类（登录失效 / 频控 / 业务失败分流），夸克的风控比 PikPak 严，这层是必需的。
3. **一键自检**：设置 → 关于 → 运行自检，依次探活登录态、目录列表、回收站、直链接口，改版后 10 秒定位坏在哪一环。
4. **内置预览 + 磁链快捷提取**：文本预览里直接识别链接并一键复制。
5. **分类保留策略**：清理/查重共用一套「保留最新/最旧/最大/最小/名称长短」语义，避免各模块各写一套。

## 四、风险与注意事项

1. **未公开接口**：夸克网盘没有官方公开 API，本脚本走的是网页端内部接口。官方调整后可能局部失效，届时改 `EP` 表即可（见 `docs/接口校准清单.md`）。
2. **合规**：《夸克用户协议》对自动化访问有约束。脚本的请求频率刻意做了节流（默认并发 4 / 最小间隔 120ms），但仍建议低频使用，不要用于批量刷取。
3. **删除可逆**：所有删除操作只进回收站，不做永久删除；查重/清理默认只扫描，删除前必弹确认。
4. **直链有时效**：夸克直链带鉴权与过期时间，导出后请立即使用。
5. **License**：原项目为 AGPL-3.0-or-later，本版作为衍生作品沿用同一许可。若你要分发修改版，必须同样开源并提供完整源码。

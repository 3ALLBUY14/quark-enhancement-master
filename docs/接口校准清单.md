# 接口与校准清单

本脚本通过夸克网盘**网页端内部接口**工作。接口未公开、可能随时变动。所有路径集中在脚本头部 `EP` 表（`Quark_Enhancement_Master.user.js` 第 1034 行起），改版时只改这张表。

- 基址：`https://drive-pc.quark.cn/1/clouddrive`
- 公共查询参数：`pr=ucpro&fr=pc&uc_param_str=`，每次请求额外附加 `__t=<毫秒时间戳>&__dt=<随机数>`
- 鉴权：浏览器 Cookie 会话（`__pus` / `__puus`），请求以 `credentials: 'include'` 发起
- 响应统一结构：`{ status, code, message, data, metadata }`，成功判定为 `status === 200 && code === 0`
- 列表分页元数据：`metadata._total` / `_count` / `_page`

## 一、脚本使用的端点

| 用途 | 方法 | 路径 | 关键参数 |
|---|---|---|---|

| 新建文件夹 | POST | `/file` | `pdir_fid` `file_name` `dir_path=""` `dir_init_lock=false` |
| 重命名 | POST | `/file/rename` | `fid` `file_name` |
| 移动 | POST | `/file/move` | `filelist[]` `to_pdir_fid` `exclude_fids=[]` |
| 删除（进回收站） | POST | `/file/delete` | `action_type=2` `filelist[]` `exclude_fids=[]` |
| 获取直链 | POST | `/file/download` | `fids[]` → 返回 `download_url` `md5` |
| 容量/会员 | GET | `/member` | — |
| 任务轮询 | GET | `/task` | `task_id` `retry_index` → `status`（2 完成 / 3 失败） |
| 创建分享 | POST | `/share` | `fid_list[]` `title` `url_type`(1 公开/2 私密) `expired_type`(1 永久/2 一天/3 七天/4 三十天) → `task_id` |
| 获取分享链接与提取码 | POST | `/share/password` | `share_id` → `share_url` `passcode` |

## 二、实机校准方法（30 秒定位）

某功能报错时，按下面顺序找出是哪一环坏了：

1. **打开自检**：设置 → 关于 → 运行自检
   依次探活「登录态 → 目录列表 → 回收站 → 直链接口」。
   - 登录态失败 → 未登录或 Cookie 过期，刷新页面重登
   - 仅某一环失败 → 该接口路径变了，进入第 2 步
2. **抓真实请求**：在夸克网盘页按 `F12` → Network → 手动做一次对应操作（如重命名一个文件）→ 找到那条请求
   - 对比 `Request URL` 的路径与查询参数
   - 对比 `Payload` 的字段名
3. **改 `EP` 表**：把新路径/新字段名填回脚本头部的对应条目，保存即生效，不需要动任何业务代码
4. **回归**：重跑自检，或直接用 `__QEM__` 调试入口：

```js
__QEM__.api.raw('list', { pdir_fid: '0', page: 1, size: 10 })   // 直接打接口
__QEM__.EP.list                                                  // 查看当前端点定义
__QEM__.config.data                                              // 查看配置
```

## 三、已知不确定项

以下三处基于社区实现推导，未在实机全面验证，如遇失败优先核对：

| 项 | 说明 |
|---|---|
| `/file/move` 的 body 字段名 | 社区通行写法为 `filelist` + `to_pdir_fid` + `exclude_fids`。若报参数错误，抓一次官方「移动到」请求核对 |
| `/file/recycle/*` 三个路径 | 回收站接口在不同客户端版本命名略有差异（`recycle/list` vs `recycle`）。校准方法同上 |
| `/share/cancel` 的 body | 字段为 `share_id_list`，若失败抓一次官方「取消分享」请求 |

## 四、请求节流建议

夸克侧风控比 PikPak 严。默认参数：并发 4、最小间隔 120ms。若出现 `429` / 「请求频繁」类返回：

1. 设置 → 常规 → 提高「最小间隔」（建议 300–500ms）、降低「并发数」（建议 2）
2. 递归扫描（查重/目录树/清理）尽量限定在小范围目录内执行
3. 避免在短时间内反复触发大范围扫描；扫描结果有本地索引缓存（同目录二次扫描会命中缓存）

# 夸克增强大师

夸克网盘增强用户脚本。移植自 [PikPak Enhancement Master](https://github.com/digbug82/PikPak_Enhancement_Master) v5.3.0，保留其核心功能定位与交互范式（**工作台面板 → 多选 → 快捷键驱动的批量操作**），全部实现按夸克网盘接口重写。

- 版本：v0.1.3
- 许可：AGPL-3.0-or-later（与原项目一致）
- 产物：`Quark_Enhancement_Master.user.js`（单文件，直接安装）
- 上游：[PikPak Enhancement Master](https://github.com/digbug82/PikPak_Enhancement_Master)（AGPL-3.0，衍生关系见 [NOTICE.md](NOTICE.md)）

[![CI](https://github.com/3ALLBUY14/quark-enhancement-master/actions/workflows/ci.yml/badge.svg)](https://github.com/3ALLBUY14/quark-enhancement-master/actions/workflows/ci.yml)


## 安装

1. 浏览器安装 Tampermonkey（或 Violentmonkey）
2. 打开 Tampermonkey 面板 → 添加新脚本 → 粘贴 `Quark_Enhancement_Master.user.js` 全文 → 保存
3. 打开 <https://pan.quark.cn> 并登录，页面右下角出现 ☁ 悬浮球

## 使用

| 入口 | 说明 |
|---|---|
| ☁ 悬浮球 | 打开工作台（可拖拽到任意位置，位置会被记住） |
| `Alt+Q` | 开关工作台 |
| `Alt+S` | 打开设置 |
| Tampermonkey 菜单 | 各功能快捷入口 |

工作台内：**单击**行选中 → **双击**文件夹进入 / 双击文件预览 → 点列头排序（每个目录独立记忆）。

快捷键在面板打开时生效：`F2` 批量重命名、`F8` 新建文件夹、`Delete` 删除、`Alt+D` 下载、`Alt+U` 文件查重、`Alt+I` 文件透视、`Alt+Z` 撤销、`Alt+H` 操作历史、`Ctrl+A` 全选、`Ctrl+I` 反选、`Ctrl+C/X/V` 复制/剪切/粘贴、`Esc` 取消选择。设置面板中可自定义。

## 可靠性设计（重点）

上游项目累计 772 次提交都没有解决的四类问题，本版作为一等公民实现：

### 1. 批量操作可撤销

工具栏「↩ 撤销」或 `Alt+Z`。所有批量操作在落盘前记录操作前的状态，支持四类撤销：

| 操作 | 撤销方式 |
|---|---|
| 批量重命名 | 逐项写回原文件名 |
| 批量移动 / 粘贴 | 按原父目录分组回移 |
| 批量删除 | 通过删除后登记的回收站条目还原（按名称+体积匹配） |
| 分享转存 | 删除转存生成的文件 |

撤销栈持久化在本地，默认保留最近 20 次（可调）。`Alt+H` 打开**操作历史**，兼作审计日志，可导出 TXT/JSON，逐条查看涉及的文件明细与操作前后状态。

> ⚠️ 删除类撤销依赖回收站：若回收站已被清空或超出保留期，该项会标记为「不可撤销」并说明原因，不会静默失败。

### 2. 同名冲突策略

移动 / 粘贴 / 转存遇到目标目录已有同名项时，**不再静默处理**，可选四种策略（设置 → 可靠性）：

| 策略 | 行为 |
|---|---|
| 每次询问 | 弹窗列出命中项，可选「跳过 / 自动重命名 / 覆盖」，可勾选记住选择 |
| 跳过同名项 | 仅处理不冲突的项目，明确告知跳过了几项 |
| 自动重命名 | 给冲突项加 `_1` / `_2` 序号后继续 |
| 覆盖 | **先把目标同名项移入回收站**再继续，执行前二次确认 |

### 3. 容量预检

消耗空间的操作（如转存）执行前先读容量并预估增量；空间不足时明确提示「需要多少 / 剩余多少」，而不是等官方静默中止后让用户猜为什么文件没出现。设置 → 可靠性 可查看当前用量与剩余空间。

### 4. 熔断与缓存列表保护

- **熔断**：接口连续失败达阈值（默认 6 次）后暂停请求 30 秒并给出明确提示，避免官方异常时无限重试刷屏。可在设置中调整阈值/时长，或点「立即解除熔断」。
- **错误归类**：登录失效 / 频控 / 网络异常 / 业务错误四类分流，网络异常单独计入熔断。
- **缓存列表保护**：目录加载失败时降级展示本地缓存列表，并在工作台底部标注缓存时间与原因，**不再把列表清空**（上游 issue #20「升级后文件不显示」的典型现场）。

### 5. 目录快照与差异对比

撤销只能回滚**本脚本发起的操作**，管不了外部误删、其他客户端改动或官方静默覆盖。快照 diff 用来事后发现这些问题。

1. 对重要目录建一份**基线快照**（可选递归整棵子树）
2. 之后任意时间再采集一次，两份快照做对比
3. 差异分四类输出：**新增 / 缺失 / 内容变化（体积或时间）/ 位置变化（同名称同体积跨路径）**，并给出体积增减统计

可导出差异报告 TXT、复制缺失/变化清单。快照压缩后存本地，最多保留 10 份（超出自动裁剪最旧的）。

### 6. 回收站临期预警

夸克回收站默认保留 **30 天**，过期永久删除。本版：

- 回收站列表增加「**预计剩余**」列，≤ 预警天数标红、≤ 2 倍预警天数标黄
- 打开工作台时静默检查一次，有临期项会提示（可关闭）
- 「还原选中项」在未勾选时**默认还原临期项**，避免误操作
- 剩余天数优先采用接口返回的官方过期字段，取不到才按删除时间 + 保留期估算，并在界面注明

### 7. 配置版本历史与回滚

配置是唯一「误操作后无法自我恢复」的数据 —— 改错一个开关、被导入覆盖、误点重置，原本都没有退路。

- **自动留痕**：配置每次变更自动记一版（5 分钟节流 + 内容去重，最多保留 20 版），也可随时手动存档并写备注
- **键级差异**：任选一版与「当前配置」对比，逐项列出配置项 / 原值 / 现值
- **一键回滚**：恢复前会**确保当前配置已被留档**（已有相同记录则不重复留档），所以回滚本身也能再回退
- 支持单版导出为 JSON、按版本删除、清空全部、开关自动快照

### 8. 空间占用分析

网盘容量条 + 四维聚合排行（带占比条）：**单个文件 Top N**（10/20/30/50/100）/ **按扩展名** / **按文件类型** / **按一级子目录**；可过滤体积下限，支持导出 CSV、复制清单、直接清理（走回收站且可撤销）。

## 功能

**整理**
- 批量重命名：查找替换 / 正则 / 前后缀 / 序号（起始·步长·位数·位置·分隔符）/ 大小写 / 全半角 / 扩展名改写 / 名称截取 / 特殊字符清理 / 模板（`${name} ${ext} ${n} ${date} ${rand}`），带**逐条新旧名预览与冲突检测**，重名自动加序号规避
- 文件查重：同体积 / 同体积+名称归一化 / **精确 MD5 比对**（复用下载接口返回的 md5，无需下载文件），保留策略可选（最新/最旧/最大/最小/名称长短）
- 文件夹查重：子项内容签名完全相同 或 名称相似度（二元组 Jaccard）双维度判定
- 资源清理：空文件夹 / 0 字节文件 / 超大文件 / 长期未修改 / 指定扩展名，仅列出，确认后处理

**导出**
- 目录树：Markdown / TXT（树形） / JSON，含体积与类型统计
- M3U 播放列表（可选写入直链）
- TXT/MD/SRT 磁链提取（magnet / ed2k / thunder / 直链），去重后汇总
- CSV 清单、直链清单、IDM URL/BAT 清单

**下载与播放**
- 直链导出、Aria2 JSON-RPC 推送（含连接测试）、IDM 清单导出、浏览器直接下载
- 外部播放器：PotPlayer 协议直达（支持自定义 exe 路径绕过注册表异常）/ 复制直链
- 以图搜图：Google Lens / Yandex / SauceNAO / trace.moe

**分享**
- 批量创建分享（公开/私密 × 有效期），自动取回链接与提取码
- 分享解析：粘贴链接 → 浏览目录 → 勾选转存到指定文件夹
- 我的分享：列表、浏览/转存计数、一键取消分享

**其他**
- 回收站：列表 / 剩余天数预警 / 还原 / 彻底删除 / 清空
- 空间占用分析：容量条 + 单文件/扩展名/类型/一级目录四维排行，可直接清理
- 文件属性面板、内置预览（图片/音视频/文本，文本附磁链快捷提取）
- 请求节流（并发数 + 最小间隔，降低风控概率）
- 配置导出/导入、配置版本历史与回滚、缓存清理、一键自检

## 安全与边界

- **不读取、不上传任何账号凭证**。所有请求由夸克页面自身发起，凭据即浏览器已有的登录态，脚本不接触 Cookie 内容（仅在可读时用于兼容部分需签名的接口）。
- **所有删除动作只进回收站**，不做永久删除；回收站内的永久删除/清空需二次确认。
- **批量操作可撤销**，且落盘前记录操作前状态；撤销栈与操作日志仅保存在本地浏览器，不外传。
- **同名冲突不再静默处理**，覆盖前必须二次确认，且被覆盖项只进回收站。
- **快照与差异报告**存在本地浏览器，不包含文件内容，仅名称/体积/时间/标识；不上传任何数据。
- 查重与清理**默认只扫描不删除**，删除前必弹确认，并提示可还原。
- 接口为夸克未公开的内部接口。若官方改版导致某项功能失效，只需调整脚本头部 `EP` 端点表，无需改业务逻辑，详见 `docs/接口校准清单.md`。

## 开发

```bash
npm install          # 安装 jsdom / eslint
npm run verify       # 一次跑完：语法检查 + ESLint + 冒烟测试
```

| 命令 | 作用 |
|---|---|
| `npm run check` | `node --check` 语法检查 |
| `npm run lint` | ESLint（未声明标识符、重复声明、不可达代码、危险动态执行等） |
| `npm test` | jsdom 冒烟测试，**126 项断言** |
| `npm run verify` | 上面三项串行执行 |

CI：`.github/workflows/ci.yml` 在 push / PR 上跑完整校验链，另含**用户脚本头与版本一致性校验**（`scripts/check-userscript-header.mjs`，防止头部 `@version`、脚本内 `VERSION`、`package.json` 三处版本漂移）。

> 若不想装依赖，也可复用已有的 node_modules：
> `NODE_PATH=<某处>/node_modules node tests/smoke-test.js`

测试覆盖：启动无异常、工具函数、重命名规则引擎全部规则、接口请求参数、文件模型归一化、递归扫描、工作台 UI 渲染与选择模型、列头排序持久化、导出与直链解析；可靠性八项（对话框返回值回归、同名冲突四种策略、容量预检、撤销四类链路、熔断开启/拒绝/绕行/恢复、缓存列表降级、**配置展平/差异识别/回滚与自动备份/自动快照节流与去重/上限裁剪**、**统一删除入口的撤销登记**）；防丢失三项（快照打包/四种差异识别/端到端比对、回收站剩余天数与临期筛选、**空间占用四维聚合**）。

> 回归保护：`confirm/prompt 点确定应返回确定值`、`失败时不应清空列表`、`版本号三处一致` 三条断言，分别守住一次真实缺陷（`close()` 触发 `onClose` 抢先决议导致确定按钮失效）与两类高发回归（上游 issue #20 场景、版本漂移）。
